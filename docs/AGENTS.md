# Documentation guidance

- Teach TOOLPATHS through the included Grasshopper example definitions. Link to the relevant definition so users can open and inspect the complete workflow.
- Do not repeat a tutorial in prose when the example file already demonstrates it. Explain concepts once where needed, then link to examples for hands-on learning.
- Use **Toolpath inheritance** for settings passed from one Toolpath to another. Avoid calling an inherited Toolpath a “template”; there is no separate linked-template feature.
